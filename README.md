# SHIFT — умный планировщик жизни (Apple Calendar style)

Отдельная, независимая версия приложения — тот же функционал, что и в
основном репозитории, оформление в духе Apple Calendar (светлая/тёмная
тема, красный акцент по умолчанию, сегментированные переключатели,
кружок вокруг сегодняшней даты).

Без сборки (npm/vite не нужны) — React грузится с CDN прямо в браузере.

## Файлы

- `index.html` — всё приложение целиком
- `manifest.json` — установка на главный экран
- `service-worker.js` — кэширование для офлайна
- `icon-*.png`, `favicon-32.png` — иконки

## Как опубликовать на GitHub Pages

1. Создай **новый** репозиторий на GitHub (отдельный от основного).
2. Загрузи туда все файлы этой папки одним выделением
   («Add file → Upload files»). Если кнопка загрузки не реагирует в
   Safari на iPhone — используй `github.dev` (замени `github.com` на
   `github.dev` в адресной строке уже открытого репозитория) или
   отредактируй/создай файл `index.html` напрямую через веб-редактор
   GitHub (карандаш / «Create new file»).
3. Settings → Pages → Source: "Deploy from a branch", branch `main`,
   `/ (root)` → Save.
4. Через 1–2 минуты сайт будет на
   `https://<логин>.github.io/<репозиторий>/`.

## Тема и акцент

В Настройках внутри приложения: переключатель «Тёмная / Светлая» и
выбор акцентного цвета (по умолчанию — красный, как у Apple; можно
вернуть золотой или выбрать другой).

## Данные

Хранятся только в этом браузере на этом устройстве (localStorage).
Экспорт/импорт резервной копии — тоже в Настройках.
